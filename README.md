<h1 align="center">droltr</h1>
<p align="center">Networking, virtualization, and systems administration.</p>

<br>

Long-standing focus on Proxmox VE, Fortinet, Linux hardening, and network diagnostics. More recently, learning to work with AI-assisted development tools.

Occasionally reverse-engineers hardware — mostly RGB controllers and AIO LCD displays — as a way to keep learning.
